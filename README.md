🌐 Personal Portfolio

A responsive personal portfolio website built with pure HTML, CSS & JavaScript.
No frameworks — everything built from scratch!

✨ Features
- Custom animated cursor
- 3D tilt card effect
- Typewriter animation
- Particle canvas background
- Scroll reveal animations
- Parallax orb effects
- Glitch hover effect
- Magnetic buttons
- Scroll progress bar
- Fully responsive

 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

 🚀 How to Run
1. Download the files
2. Open index.html in any browser
3. That's it!
